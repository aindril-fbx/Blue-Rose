# BLUE ROSE

A fun, experimental handheld console built using an ESP32 and a small OLED display. 

<img src="images/GitHubImages/IMG20251229181103.jpg" width="300">


## What It Can Do

* Menu-based UI on an OLED display
* Button-controlled navigation
* Small games and interactive experiments
* Clock utilities like digital clock and Pomodoro timer
* Deep sleep support for low power usage

## Fun Ideas and Future Plans

* Bluetooth laptop control (media keys, shortcuts, slides)
* Digital pet / virtual companion on the OLED
* More mini games
* Spotify control over Bluetooth

## Tech Stack

* ESP32
* OLED display with u8g2
* PlatformIO with Arduino framework
* C++
